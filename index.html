查看部署思路

无服务器架构（AWS）

用 Serverless 方案搭建后台上传与前台分发，轻量、弹性、免运维。

静态前台

Amazon S3 + CloudFront

HTML/CSS 前端托管在 S3，CloudFront 全球加速，展示纯净、快速、稳定。

媒体存储

作品原图存放在 S3

管理后台上传图片到 S3，使用生命周期与版本控制，保证高质量与安全性。

后台接口

API Gateway + Lambda

无服务器函数处理上传、写入元数据，低成本扩展；可结合 Step Functions 做批处理。

身份与权限

Amazon Cognito

为管理后台提供登录、角色管理，确保只有授权账号可上传或调整作品信息。

数据索引

DynamoDB 元数据

以作品系列、标签、发布时间索引文件，前台按需读取生成作品墙。
