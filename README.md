# Personal Photo Portfolio (Serverless)

This repository contains an end-to-end example for a personal photography showcase site using AWS serverless services. It includes architecture notes, infrastructure as code, backend Lambda handlers (TypeScript), and a Vue 3 + Vite frontend skeleton.
